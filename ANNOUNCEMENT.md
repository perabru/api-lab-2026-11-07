# Explore relações. Imagine criaturas.

**Fable Atlas API · Dia 05/10 · 07/11/2026**

Um catálogo local de oito criaturas fictícias originais, com quatro tipos e quatro habilidades. Busca sem diferenciar acentos/maiúsculas, filtros combinados, detalhes relacionados, relações reversas e paginação que preserva filtros.

**Node.js 22+ · sem dependências externas · 10 testes aprovados**

```bash
git clone https://github.com/perabru/api-lab-2026-11-07.git
cd api-lab-2026-11-07
npm run check:data
npm run demo
npm test
npm start
```

O validador de dados ajuda novas contribuições a manter IDs únicos e vínculos válidos. A demo verifica páginas e relações sem gravar arquivos. Experimente, sugira um filtro por issue ou contribua com uma criatura original.

Apoio voluntário por Pix destacado no README: bruno.pera@unifesp.br. Incentiva a continuidade; o código permanece aberto e gratuito.

**English:** A local catalog of original fictional creatures with related types and abilities, combined filters, accent-insensitive search and pagination. Ten tests passed. Explore the demo and data validator; contribute an original creature or reproducible edge case.
